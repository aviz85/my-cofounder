# מה קורה בקבוצה

דמו. בשיעור החי מחליפים את זה בפלט אמיתי של:

```bash
node scripts/wa.mjs read --group <id>@g.us --count 15
```

את מזהה הקבוצה מעתיקים מ-WhatsApp Web עם Joni (סמל שני המלבנים).

## סיכום לדוגמה (להחלפה בחי)

- דנה שאלה מתי המפגש הבא.
- יוסי שלח קובץ ולא קיבל אישור שזה הגיע.
- שלוש הודעות תפעוליות, בלי החלטה.

## מה הסוכן עושה עם זה

1. קורא את הקבוצה.
2. כותב כאן סיכום קצר בעברית.
3. מציג טיוטת מענה.
4. רק אחרי אישור - שולח טקסט או הקלטה.
